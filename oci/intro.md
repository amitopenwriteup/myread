## Module 1: Containerization Overview

Then we move into our first core topic: **Containerization**. [pause]

We'll start with *why* containers matter and what problems they solve. We'll look at the **Docker components**, and you'll get hands-on with **basic Docker commands**. [pause]

## What Comes Next (Roadmap)

Once containers are clear, we'll build step by step:

- **Container Registry (OCIR)**: create repositories, push and pull images, and manage them.
- **Kubernetes Basics**: architecture, main components, and essential `kubectl` commands.
- **OKE and Managed Nodes**: Basic vs. Enhanced clusters, virtual nodes, networking, policies, and building clusters with *Quick Create* and *Custom Create*.
- **Cluster Access**: kubectl, Cloud Shell, local terminal, SSH, and bastion setups.
- **Virtual Nodes and Self-Managed Nodes**.
- **Deployments**: multi-tier apps, load balancers, ingress, Arm and GPU workloads.
- **Storage**: block volumes and File Storage with PVCs.
- **Administration**: scaling, autoscaling, upgrades, and observability.
- **Security**: RBAC, secrets, image scanning, signing, and encryption.
